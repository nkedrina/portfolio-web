## AI-MANAGED

Следующая информация была проверена по реальным файлам проекта и может поддерживаться AI при дальнейшей работе.

### Точные точки входа

- `index.html` — основная HTML-оболочка приложения и главный открываемый документ.
- `about.html` — HTML-оболочка маршрута `/about`.
- `portfolio.html` — HTML-оболочка маршрута `/portfolio`.
- `exhibitions.html` — HTML-оболочка маршрута `/exhibitions`.
- `contacts.html` — HTML-оболочка маршрута `/contacts`.

### Основные маршруты hash-SPA

- `/` — главная страница.
- `/about` — страница «Обо мне».
- `/portfolio` — каталог проектов.
- `/portfolio/<project-id>` — детальная страница проекта, например `/portfolio/aqualumina`.
- `/exhibitions` — список выставок и фестивалей.
- `/contacts` — специальный hash-маршрут страницы контактов; в `render.js` он может обрабатываться через рендер главной с прокруткой к `#contacts`.

### Сопоставление HTML-путей и hash-маршрутами

- `index.html` → `#/`
- `about.html` → `#/about`
- `portfolio.html` → `#/portfolio`
- `exhibitions.html` → `#/exhibitions`
- `contacts.html` → `#/contacts`

Проверенное сопоставление находится в функции `normalizeInitialPath()` в `render.js`.

### Реальные ключевые файлы

- `data.js` — глобальная модель данных и нормализация медиа-URL.
- `utils.js` — общие вспомогательные функции и `window.PORTFOLIO_UTILS`.
- `render.js` — маршрутизация, рендеринг, обработчики, галереи, темы и медиа-механизмы.
- `script.js` — более ранний дублирующий набор данных; в существующем load-порядке не является актуальной моделью после загрузки `data.js`.
- `style.css` — все общие стили приложения.

### Реальные ключевые DOM-элементы

- `#main` — контейнер динамически рендеримых страниц.
- `#hdr` — фиксированная навигация.
- `#footer` — динамически формируемый footer.
- `#themeBtn` — кнопка переключения темы в HTML-каркасе.
- `#modal` — legacy-контейнер модального проекта.
- `#quick` — контейнер quick-preview проекта.
- `#toast` — контейнер уведомлений.
- `#contacts` — секция контактов, к которой выполняется прокрутка при обработке `/contacts`.
- `#pfList` — контейнер сетки отфильтрованного портфолио.

### Ключевые data-атрибуты и состояния

- `data-theme` — тема на корневом `<html>`; допустимые значения из runtime-кода: `light`, `dark`.
- `data-p` — ключ навигационного маршрута на `<a>` в header.
- `data-theme-toggle` — элемент переключения темы.
- `data-quick` — ID проекта для открытия quick-preview.
- `data-quick-full` — ссылка на полный проект из quick-preview.
- `data-quick-close` — кнопка закрытия quick-preview.
- `data-cat` — ID выбранной категории портфолио.
- `data-scroll` — CSS-селектор для прокрутки к элементу.
- `data-file` — ключ PDF-ссылки: `cv` или `portfolioPdf`.
- `data-src` — лениво загружаемый обычный медиа-путь.
- `data-art` — ключ параметров Canvas-заглушки в реестре `reg`.
- `data-close` — действие закрытия modal-механизма с возвратом на портфолио.
- `data-top` — действие прокрутки наверх.
- `aria-pressed` — текущее состояние фильтра категории портфолио.
- `aria-current="page"` — активный пункт навигации.
- `body.home` — признак главной страницы.
- `body.lock` — блокировка прокрутки при открытом modal или quick-preview.
- `body.hh` — признак скрытого header.
- `hdr.top`, `hdr.hide` — CSS-состояния header.

### Проверенные глобальные объекты и namespace

- `window.PORTFOLIO_DATA` — центральный объект данных с полями:
  - `A` — данные автора и общие ссылки;
  - `CATS` — категории портфолио;
  - `PROJECTS` — массив проектов;
  - `EXH` — массив выставок и фестивалей;
  - `PROJECT_SECTION_ORDER` — вспомогательный экспорт в области `data.js`, не являющийся полем объекта `PORTFOLIO_DATA`.
- `window.PORTFOLIO_UTILS` — утилиты:
  - `$`
  - `RM`
  - `esc`
  - `sortedEx`
  - `pad2`
  - `place`
  - `cityLine`
  - `TAG`
- `window.VERCEL_BLOB_BASE` — оставлен как пустая совместимая переменная без внешнего base.
- `window.toAssetUrl` — нормализатор локального медиа-пути без преобразования в Blob URL.
- `window.normalizeAssetUrls` — рекурсивная нормализация локальных медиа-путей.

### Конфигурация сборки

- В корне не найдено `package.json`.
- Не найдены npm/pnpm/yarn lock-файлы.
- Не найдено отдельного конфигурационного файла сборщика или TypeScript-конфигурации.
- Проект использует статические HTML/CSS/JS-файлы без явного сборочного процесса в проверенных корневых файлах.

### Неопределённые или legacy-сведения

- `script.js` является дублирующим источником данных, но точный статус его устаревания должен сохраняться как описательный факт без удаления файла.
- `openModal(id)` определяется в коде, но не вызывается обнаруженным документным обработчиком или hash-маршрутизацией.
- `socialLink(s)` определяется в коде, но в runtime-коде вызов не обнаружен.
- Объект `titles` определён в `render.js`, но в проверенном runtime-коде не используется.
